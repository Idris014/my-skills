# 参数与命名护栏

这些数值是起点和安全区间，不是固定配方。始终根据肤色、直方图、原始光源、服装纹理和用户审美回调。

## Lightroom

### 全局

- Exposure：先保证肤色与主体可读，再保护浅色衣物和脸部高光。
- Highlights：高光偏硬时可从 `-10` 到 `-35` 试起。
- Shadows：需要打开暗部时可从 `+5` 到 `+25` 试起。
- Whites / Blacks：小幅建立黑白场，避免同时把两端推到剪切。
- Curve：优先轻微 S 曲线；不要用过强曲线替代局部蒙版。

### `LR｜人物｜增强`

- Exposure：中等起点 `+0.20` 到 `+0.50 EV`
- Shadows：`+10` 到 `+30`
- Whites：`0` 到 `+10`
- Texture / Clarity：通常 `-5` 到 `+5`；人像不以“锐”为目标
- Amount：套用自适应预设后先从较低强度回看

### `LR｜背景｜压暗`

- Exposure：中等起点 `-0.30` 到 `-0.80 EV`
- Highlights：`0` 到 `-30`
- Blacks：`0` 到 `-15`
- Saturation：背景抢色时 `0` 到 `-15`
- 不让人物边缘的背景突然变黑；出现光晕先修蒙版

### 面部区域

- Facial Skin 的负 Texture 通常从 `-5` 到 `-15` 开始；不以消除毛孔为目标。
- Eye Sclera / Teeth 先轻降 Saturation，再轻提 Exposure；纯白会显得假。
- Lips 的 Hue / Saturation 先小幅变化，并同时查看全图与 100%。

## Photoshop 顺序与几何一致性

- 默认顺序：`PS_FACE → PS_SKIN`。先固定 Eye Size、Jawline、Face Width 等几何，再绘制眼下、面颊和下颌的瑕疵修复与中性灰笔触。
- 空白 50% 灰层可以在液化前预先建立，但不要在阶段 2 完成前开始实际绘制。
- 已有中性灰层时先验证是否包含非 50% 灰像素。只有图层存在或名称正确，不能证明已经完成磨皮。
- 若旧中性灰已有笔触而五官尚未液化，默认隐藏并保留为 `旧版参考｜液化前中性灰`，在最终几何上重建受影响笔触；不要把旧笔触直接留在液化层上方继续使用。
- 若用户明确只要求磨皮、不需要五官修饰，可记录 `PS_FACE=skipped_by_user`，锁定当前几何后进入中性灰阶段。

## Photoshop 中性灰

- 图层：50% Gray，Soft Light
- 画笔：Soft Round
- Opacity：`100%`
- Flow：`3–7%`，默认 `5%`
- Hardness：`0%`
- Smoothing：约 `10%`
- 工作缩放：`100–200%`
- 整体复查：`25–50%` 与 Fit on Screen
- 默认保持中性灰层 Opacity `100%` 完成 A/B；仅在确认偏重后降到 `70–90%`

完成门槛：在 50–100% 的同视图 A/B 中，目标低频明暗块应能快速辨认出变均匀；在 100–200% 仍须保留毛孔、骨相和真实高光边缘。图层存在或包含少量笔触不等于完成。第一轮不可辨时，在正确目标区执行第二轮可控叠加；Flow 最高 7%，仍不可辨则报告未达标。

重点顺序：最终面部几何确认 → 独立层处理明显暂时性瑕疵 → 额头 → 眼下 → 鼻翼 → 嘴角 → 面颊。保留痣、雀斑、身份特征或长期皮肤特征，除非用户明确要求移除。

## Photoshop 五官液化

- 独立层/智能对象命名 `PS｜五官｜自然液化`。
- 默认联动双眼。
- 中等档：Eye Size `+3`、Jawline `-4`、Face Width `-3`。
- 强化档：Eye Size `+4` 到 `+5`、Jawline `-5` 到 `-6`、Face Width `-4` 到 `-5`；逐项增加并切换 Preview。
- Nose、Mouth、Smile 默认 `0`，用户点名后从绝对值 `1–3` 开始。
- 单个参数绝对值超过 `8` 前暂停并说明原因。
- 完成门槛：50–100% 同视图 A/B 中，1–2 秒内可辨认眼部精神感或轮廓改善；Fit on Screen 不得出现身份、表情或年龄感跳变。
- Preview 切换时若身份、表情或年龄感明显改变，数值减半；仍不自然则归零。
- 五官液化与衣物液化分层，不在同一不可区分的像素层上连续写入。

## Photoshop 衣物

### 液化

- 优先复制 Lightroom 工作底图/智能对象，置于原底图上方、中性灰层下方；再 Smart Object → Liquify。
- 用宽松衣物蒙版或 Liquify Freeze 限定范围；形变后的新轮廓不能被蒙版切掉。
- 盖印层只是上游快照，不会自动继承后续修改；上游变化后必须重建。
- Brush Size：略大于待收整的鼓包或轮廓段。
- Pressure：低压，多次短推；避免一次大幅拖拽。
- Freeze：人体、饰品、Logo、背景直线、缝线和不应移动的边缘。
- Preview：每完成一个局部切换一次。
- Reconstruct：只要直线、比例或纹理方向不对就回退，不用更多液化掩盖错误。
- 验收必须同时满足：鼓包完全消失；目标轮廓自然、连续、无残留曲度/波浪/折线；人体、背景、Logo、缝线和布纹未受损。
- 任一项失败即完整回退本轮衣物修改并报告放弃；禁止降低不透明度、重复 Liquify、表面模糊或修复画笔来掩盖形态失败。

### 局部纹理

- 空白层命名 `PS｜衣物｜纹理修补`。
- Healing/Clone 使用 Current & Below 或 Sample All Layers。
- 取样点靠近目标且纹理方向一致；短笔触，分区取样。
- 表面模糊只可作为低强度、被严密蒙版限制的细碎纹理辅助手段，不解决轮廓。

## 推荐图层结构

从上到下：

```text
观察｜明暗增强             [最终隐藏]
观察｜黑白                 [最终隐藏]
PS｜妆容｜眼               [如需要]
PS｜妆容｜唇               [如需要]
PS｜妆容｜肤色             [如需要]
PS｜衣物｜纹理修补         [空白像素层]
PS｜皮肤｜中性灰｜柔光｜流量5%
PS｜皮肤｜瑕疵修复         [空白像素层，Sample All Layers]
PS｜五官｜自然液化         [独立智能对象/智能滤镜]
PS｜衣物｜液化轮廓         [工作底图副本/智能滤镜/衣物范围]
工作底图 / Lightroom 副本
原始保留                  [锁定或独立文件]
```

## 回退规则

- 肉眼不可辨：先确认切换的是目标图层、使用规定倍率并验证图层内容/智能滤镜参数；命中正确区域后按对应阶段的强化档再做一次。仍不可辨则报告未达标，不把“自然”当作无差异的理由。
- 效果范围错误：删除或重做蒙版，不在错误蒙版上继续叠效果。
- 液化破坏比例：Reconstruct 或关闭智能滤镜，从较大画笔、较低压力重新开始。
- 衣物候选无法完全推平且保持自然无曲度：恢复衣物阶段前状态，删除或关闭本轮候选层并放弃，不继续叠加。
- 五官液化明显改变身份、表情或年龄感：参数减半；仍不自然则归零。
- 中性灰笔触建立在液化前几何：不要只把液化层插到旧中性灰下方；隐藏旧笔触作为参考，在最终几何上重建受影响区域，或在用户明确接受可编辑性下降后封装整组再液化。
- 用户在阶段 3 后重新修改五官几何：重新检查眼下、面颊和下颌的瑕疵修复与中性灰坐标，重做错位区域。
- 低分辨率代理与母版不一致：停止置入，不放大代理；回到原尺寸文件处理。
- 用户手调后：重新读取图层/蒙版/数值，保留用户选择，不自动复原。
