# 分阶段人像精修

把 Lightroom 与 Photoshop 串成可回退的人像精修流程。先建立摄影调性与人物/背景分离，再先确定五官与脸型几何，随后按最终几何处理皮肤明暗，最后处理衣物形态和妆容。液化先于中性灰，是为了避免眼下、面颊和下颌的明暗笔触停留在液化前的旧坐标。最重要的不是一次做完，而是让用户在每个阶段都能接管、微调和决定是否继续。

执行编辑时需要 Adobe Lightroom desktop、Adobe Photoshop 与可用的 Computer Use/UI 控制能力。始终保留原始文件与分层母版。

需要参数建议、图层命名和检查细节时，读取 [references/parameter-guardrails.md](references/parameter-guardrails.md)。需要核对功能名称或官方依据时，读取 [references/adobe-sources.md](references/adobe-sources.md)。

## 不可跨越的阶段门控

按以下状态机工作：

1. `LR_BASE`：Lightroom 全局调性、人物增强、背景压暗
2. `PS_FACE`：清晰可辨、保留身份特征的五官液化；先固定最终面部几何
3. `PS_SKIN`：按液化后的最终几何完成瑕疵修复与中性灰明暗修饰
4. `PS_CLOTHING`：衣物大形态液化与局部纹理修补；不达标则完整放弃
5. `MAKEUP`：判断 Lightroom 或 Photoshop，并完成所选分支
6. `FINAL_QA`：整体检查、分层母版与派生导出

完成一个阶段后立即停止。只有用户明确回复“继续”“确认，下一阶段”或同等含义，才进入下一阶段。用户的手动修改可能改变图层、蒙版、数值和选区，因此收到继续指令后先重新读取当前应用状态，不要沿用上一阶段的控件索引或假设。

用户若只要求某一个阶段，只执行该阶段并暂停，不自动补做前后阶段。

## 强度与可见性基准

把“目标区域在规定倍率下可辨认改善”作为完成条件，而不是把“图层存在、参数非零、智能滤镜已建立”当作完成。每一阶段结束前都执行同视图 A/B：保持相同缩放、中心点和面板状态，只切换本阶段的蒙版、图层或智能滤镜。

- `LR_BASE`：在 Fit on Screen 能看出主体与背景层次更清楚，但边缘无抠图感。
- `PS_FACE`：在 50–100% 切换前后 1–2 秒内能辨认眼部精神感或面部轮廓变化；在 Fit on Screen 仍是同一人物、同一表情和年龄感。
- `PS_SKIN`：在 50–100% 能看出目标暗斑、眼下和面颊过渡变均匀；在 100–200% 仍保留毛孔与骨相。
- `PS_CLOTHING`：只接受完全通过阶段 4 强制验收的明显轮廓修正；否则完整放弃。

如果用户反馈“小眼睛开关无区别”，立即进入诊断：确认切换的是目标图层而不是观察层/父级效果，放大到规定倍率，检查图层内容或智能滤镜参数，并做同视图 A/B。确认命中正确区域但仍不可辨时，不得报告完成；按本阶段的强化档继续一次，再重新验收。强化后仍不可辨，报告未达标并暂停，不用“自然所以看不出”解释为成功。

## 每次开始前

1. 读取当前 Lightroom 与 Photoshop 窗口、活动文档、位深、尺寸、色彩空间、未保存标记、打开的模态对话框以及现有蒙版/图层。
2. 优先延续已有工作，不盲目新建重复蒙版或重复图层。
3. 检查源文件与工作文件尺寸是否一致。低分辨率预览或生成代理只能用来审阅，不能放大后作为高分辨率母版。
4. 保留原始 RAW/32-bit 文件。创建副本、版本或分层工作文件；未经用户明确授权，不覆盖原片、不拼合母版、不导出最终文件。
5. 如发现删除确认、模式转换、保存覆盖等对话框，说明现状并等待用户处理或确认，不替用户猜测。

## 阶段 1：Lightroom 调性与语义蒙版

### 1A. 全局调性

先在全局编辑中建立白平衡、整体曝光、黑白场、对比与曲线。目标是确定画面的基调，而不是在全局滑杆里把脸单独提亮。

- 先看肤色与直方图，再看背景。
- 保留皮肤高光层次，避免眼白、牙齿和浅色衣物剪切。
- 使用参考照片或预设时先降低 Amount，再逐项判断；预设是起点，不是完成状态。

### 1B. 人物与背景分开处理

建立或复用两个独立蒙版，并重命名：

- `LR｜人物｜增强`
- `LR｜背景｜压暗`

优先使用 Select Subject / Select People 建人物蒙版，使用 Select Background 或反选主体建立背景蒙版。先检查红色叠加，再用 Add / Subtract 修正发丝、手臂、衣物边缘和两腿之间的空隙。

人物蒙版以明确提升主体可读性、打开阴影、保护高光为主；背景蒙版以降低曝光、高光或饱和度为主。默认使用参考文件中的中等强度区间，不从近乎不可辨的最低值开始。不要靠同时大幅提高人物和压暗背景制造生硬抠图感。人物边缘出现亮边、暗边或色边时，先修蒙版而不是继续加大数值。

先读取当前 Lightroom 窗口中可见的模板/预设，不凭记忆猜名称。分别在人物和背景蒙版内应用各自对应的现有模板：人物使用 Portrait/Subject/Lighten 一类当前可用模板，背景使用 Background/Darken/Blur Background 一类当前可用模板；随后用 Amount 回调强度。若当前版本或当前账户没有相应模板，明确说明后才用等效滑杆手动复现。不要把人物和背景套在同一个语义蒙版中，也不要把模板步骤悄悄省略。

### 1C. 阶段检查与暂停

在适合屏幕与 100% 两种视图检查：

- 面部是否比背景更易读，但仍像同一光源下拍摄
- 发丝与衣服边缘是否无光晕
- 背景是否被压暗而没有色块、断层或脏灰
- 肤色、白衣或反光饰品是否剪切

留下 Lightroom 窗口与最需要用户微调的蒙版处于可编辑状态，然后输出阶段报告并暂停。

## 阶段 2：五官自然修饰与几何定稿

先固定最终面部几何，再在阶段 3 进行依赖位置的瑕疵修复和中性灰明暗修饰。这样眼下、面颊和下颌的笔触会落在液化后的正确坐标。五官修饰要产生清晰可辨的精神感与轮廓改善，同时不替换身份特征、不追求模板化网红脸。若用户未指定具体部位，优先调整双眼、下颌和脸宽；鼻子、嘴唇与笑容默认保持。

### 2A. 位深、工作副本与旧项目检查

- 若从 Lightroom 以 16-bit PSD/TIFF 打开，验证尺寸和色彩配置后继续。
- 若当前是 32-bit 原片，先复制文档，命名为 `原名_16bit_retouch`，再把副本转为 16 Bits/Channel。出现 HDR Tone 对话框时，以外观不漂移为目标；Exposure `0`、Gamma `1.00` 可作为中性起点，但仍须目视核对。
- 不覆盖原始 RAW/32-bit 文件，不直接在原始工作底图上液化。
- 若文档已经存在中性灰层，先验证它是否只有 50% 灰，还是已经包含实际明暗笔触。只有空白中性灰层可以原样保留到阶段 3。
- 若中性灰已有笔触而五官尚未液化，不要只在它下方新增液化层。默认保留并隐藏旧中性灰层、重命名为 `旧版参考｜液化前中性灰`，完成五官液化后在阶段 3 依据最终几何重建笔触。若用户更重视完整保留旧笔触，可提出把底图与中性灰一起封装后液化，但必须先说明这会降低中性灰的独立可编辑性并等待选择。

### 2B. 建立独立液化层

从尚未进行位置相关中性灰笔触的工作底图复制独立层，命名 `PS｜五官｜自然液化`。优先转换为 Smart Object 并使用 Face-Aware Liquify，使修改可重新进入滤镜调整。若当前 Photoshop/文档组合要求栅格化才能提交 Face-Aware Liquify，只允许栅格化这个独立副本，保留原始工作底图，并明确报告结果可通过隐藏或删除整层回退、但参数不能重新进入编辑。

不要把五官液化直接写入原始工作底图，也不要与衣物液化共用同一个不可区分的像素层。不要为了让 Face-Aware 识别更容易而先做整脸中性灰；只有某个临时瑕疵确实干扰面部识别时，才在液化源副本内部做最小范围清理。

### 2C. 两档强度调整

- 先确认 Photoshop 识别的是正确人物与正确面孔。
- 在 Fit on Screen 判断整体，在 100% 检查眼睑、瞳孔、鼻翼、唇线和发际线。
- 双眼联动调整；只有明确的不对称才拆开左右值。
- 中等档默认使用 Eye Size `+3`、Jawline `-4`、Face Width `-3`，完成第一次 A/B。
- 若 50–100% 切换时仍不能快速辨认改善，进入强化档：Eye Size `+4` 到 `+5`、Jawline `-5` 到 `-6`、Face Width `-4` 到 `-5`。逐项增加并每次切换 Preview，不一次把全部参数推到上限。
- 鼻宽、鼻高、嘴宽、上下唇和 Smile 默认保持 `0`；仅在用户点名时从绝对值 `1–3` 开始。
- 不改变瞳孔方向、眼距、种族特征、年龄特征或原有表情；不把左右脸强行做成镜像。
- 单个参数绝对值超过 `8` 前必须停下并向用户说明原因；Eye Size 不得因强化档出现明显圆睁或塑料感。

### 2D. 身份与自然度验收

保持同一缩放与中心点，切换 Preview 与 `PS｜五官｜自然液化` 可见性。必须同时满足：50–100% 下 1–2 秒内能辨认眼部精神感或轮廓改善；Fit on Screen 下人物仍一眼可辨；眼睛没有塑料感或大小跳变；下颌没有尖削折线；背景和头发未被牵动。中等档不可辨时必须尝试强化档，不能把近乎零变化报告为“自然完成”。强化档仍不可辨则报告未达标并暂停；Fit on Screen 出现身份、表情或年龄感跳变时逐项回退，必要时重置该参数为 `0`。留下五官液化层或智能滤镜可编辑并暂停。

## 阶段 3：瑕疵修复与中性灰磨皮

中性灰用于均匀皮肤的低频明暗，不是模糊纹理。它必须依据阶段 2 的最终面部几何绘制，避免笔触与眼下、面颊或下颌的新位置错开。先在独立层处理明显临时瑕疵，再用低流量 Dodge & Burn 统一额头、眼下、鼻翼、嘴角与面颊的明暗过渡。

### 3A. 几何门禁与单阶段例外

- 先确认 `PS｜五官｜自然液化` 已完成并处于最终可见状态，再开始新的位置相关皮肤笔触。
- 若阶段 2 后继续修改 Eye Size、Jawline 或 Face Width，阶段 3 的中性灰笔触不会自动跟随；重新检查眼下、面颊和下颌，必要时重做受影响的笔触。
- 若用户明确只要求磨皮并明确不需要五官修饰，可把 `PS_FACE` 记录为 `skipped_by_user`，锁定当前几何后直接执行本阶段；不得擅自改变五官。
- 对旧项目中隐藏的 `旧版参考｜液化前中性灰`，只把它作为对照，不直接恢复到液化后的画面。根据最终几何在新中性灰层重建有效笔触，用户确认后再决定是否删除旧参考。

### 3B. 建立可回退皮肤图层

按从下到上的逻辑组织：

- 工作底图或 Lightroom 副本
- `PS｜五官｜自然液化`
- `PS｜皮肤｜瑕疵修复`
- `PS｜皮肤｜中性灰｜柔光｜流量5%`
- `观察｜黑白`
- `观察｜明暗增强`

在空白 `PS｜皮肤｜瑕疵修复` 层使用 Current & Below / Sample All Layers，仅处理暂时性痘点、碎发或小范围妆面缺口；保留痣、雀斑和长期身份特征，除非用户明确要求移除。

在中性灰层使用 Soft Light 与 50% Gray。选择柔边圆画笔：Opacity 100%，Flow 3–7%，默认 5%，Hardness 0%，Smoothing 约 10%。白色提亮暗斑和凹陷，黑色压暗亮斑和突起；用 `D` 恢复黑白、用 `X` 切换。

### 3C. 中性灰明暗修饰

用短促、分次叠加的笔触，画笔略小于待修的明暗块。先完成一轮全脸低频校正，再在 50–100% A/B 标记仍无改善的目标区，返回 100–200% 做第二轮局部叠加。第二轮优先增加同一区域的可控叠加次数，不盲目提高 Flow；仅在笔触始终不落像素或多次叠加仍不可辨时，把 Flow 提到 7% 上限。不要直接刷眼睛、眉毛、鼻孔、唇线、发际线或高光边缘；这些结构被抹平会让脸失去立体感。

### 3D. 阶段检查与暂停

关闭观察层检查真实颜色，保持同一视图反复切换瑕疵修复层与中性灰层可见性。只有在 50–100% 能快速看到目标明暗块更均匀，同时 100–200% 毛孔与面部骨相仍在、左右脸不过度对称、没有灰斑或塑料感时，才报告阶段完成。若中性灰层开关无可见差异，先验证图层确有非 50% 灰像素；确认有笔触后执行第二轮局部叠加并重新验收。把中性灰层保持选中并留下低流量画笔，方便用户继续手修，然后暂停。

## 阶段 4：衣物平整

先判断问题属于哪一类：

- 轮廓、鼓包、大褶皱或挤压造成的体积问题：优先 Liquify。
- 细小折痕、断裂纹理、局部脏点或液化后的纹理接缝：使用 Healing Brush / Clone Stamp / Patch 作局部修补。

上一轮实践已经证明，“按衣物颜色选区 + 表面模糊”只能弱化细碎纹理，无法解决腰部鼓包或大面积形态问题。不要把表面模糊当成衣物推平的主方法；如果第一次结果肉眼不可辨，回退并重新判断问题类型，不要继续堆叠模糊层。

### 4A. 大面积形态

优先复制从 Lightroom 进入 Photoshop 的工作底图或其 Smart Object，命名 `PS｜衣物｜液化轮廓`，放在 `PS｜五官｜自然液化` 下方、原始工作底图上方，再把它转换为 Smart Object 后进入 Liquify。这样五官几何、皮肤瑕疵修复与中性灰仍是独立的上层修饰，不会被一张盖印快照冻结。

用经过检查的衣物选区建立宽松、可回调的图层蒙版，或在 Liquify 内冻结非衣物区域，使液化结果只影响衣物及必要的邻近轮廓。蒙版边缘应覆盖形变后的新轮廓并留有过渡，避免切边或露出双层轮廓。

只有在文档结构无法从单一工作底图液化时才建立盖印快照，并把它命名为 `PS｜衣物｜液化轮廓｜上游快照`。这类快照不会自动继承后续的上游修改；如果用户之后改动了底图或其他会影响衣物外观的图层，必须重新生成快照和液化，而不是假装已同步。

进入 Liquify 后：

- 用 Freeze Mask 保护手臂、手指、脸、饰品、Logo、关键缝线与背景直线。
- 使用比鼓包略大的 Forward Warp 画笔、较低 Pressure，以短距离多次推动。
- 从外轮廓向内收整，不把身体比例、手臂接触关系或衣摆重力方向推坏。
- 频繁切换 Preview，必要时显示 Mesh；背景竖线、图案、缝线或人体比例弯曲时立即 Reconstruct。

液化负责形态，不负责抹掉布料纹理和光影褶皱。

### 4B. 强制验收与放弃规则

衣物平整不是“尽量改善”。完成一次候选液化后，在 Fit on Screen 与 100% 同时检查目标外轮廓：

- 鼓包必须完全消失。
- 用户要求推直的轮廓必须自然、连续、无残留曲度、波浪、凹口或折线。
- 人体比例、手臂接触关系、衣摆重力方向、背景直线、Logo、缝线和布纹不得被拉坏。

只有全部通过才保留 `PS｜衣物｜液化轮廓`。若无法同时做到“完全推平”和“自然无曲度”，立即 Reconstruct、关闭智能滤镜或删除本轮衣物候选层，恢复进入衣物阶段前的画面，并明确报告“衣物平整已放弃”。不要降低验收标准，不要用降低不透明度掩盖失败，也不要用重复 Liquify、表面模糊或修复画笔继续堆叠形态问题。

### 4C. 局部纹理

如仍有明显纹理断裂，建立空白层 `PS｜衣物｜纹理修补`，用 Current & Below / Sample All Layers 的修复或仿制工具短距离补纹理。沿布料纹路和明暗方向取样，避开 Logo、领口、袖口、接缝和皮肤。

### 4D. 阶段检查与暂停

在全图与 100% 检查衣物轮廓、人体比例、手臂交叠、背景直线、Logo 与缝线。通过强制验收时留下 Liquify 智能滤镜可重新进入；未通过时恢复到衣物阶段前并留下无衣物修改的状态。随后暂停让用户判断。

## 阶段 5：妆容选择与执行

先提出推荐分支并说明理由，再执行。判断标准是：目标能否用“一个可靠的语义区域 + 一组滑杆”描述。

### 使用 Lightroom

适合整体、可批量、非破坏性的色彩或明暗调整：肤色统一、轻微降低 facial skin Texture、唇色整体色相/饱和度、眼白和牙齿的轻微亮度与去色、眉眼整体明暗。优先用 Select People 的 Facial Skin、Lips、Teeth、Eye Sclera 等当前可用区域；识别不准就改用 Photoshop。

### 使用 Photoshop

适合需要改变边缘、形状、覆盖范围或逐像素修补的任务：眼线不齐、睫毛缺口、眉形边界、唇线外溢、局部脱妆、腮红/眼影范围、左右不对称或需要精确保留毛发与皮肤高光。

在 Photoshop 中优先使用 Adjustment Layer + Layer Mask 处理颜色和明暗；像素修补放在独立空白层并启用 Sample All Layers。不要直接在底图上用高不透明度颜色涂脸。把皮肤、唇、眼和眉分成独立命名图层，方便用户回调。

### 默认建议

对单张精修照，先在 Photoshop 完成边缘、纹理与不对称修补，再在 Lightroom 对最终 PSD/TIFF 做轻量整体色彩收口。对一组照片，只需整体唇色、肤色或眼白一致时，优先 Lightroom 以便同步。

完成所选分支后，在适合屏幕和 100% 检查妆容边缘、肤质、牙齿与眼白的自然度，暂停让用户手调。

## 阶段 6：最终 QA 与交付

1. 关闭或隐藏 `观察｜黑白` 与 `观察｜明暗增强`。
2. 分别切换人物/背景蒙版、五官液化层、瑕疵修复层、中性灰层、已通过验收的衣物液化层和妆容图层；保持相同视图做 A/B，检查每一步是否达到本 skill 的可见性基准，而不只是“参数非零”。
3. 在 100%、50% 与适合屏幕三种视图检查：皮肤纹理、骨相、发丝光晕、衣物比例、背景直线、Logo、妆容边缘、白衣和高光剪切。
4. 保留分层 PSD/TIFF 母版；导出 JPEG/PNG 作为派生文件。导出前核对尺寸、色彩空间、位深和文件名。
5. 保存、覆盖、拼合或最终导出前，列出目标路径和格式并等待用户确认。
